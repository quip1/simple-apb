# Privacy policy — TEMPLATE

> **This is a template. Every instance admin must edit it before opening sign-ups.**
> The setup wizard pre-fills the instance privacy text from this file.

## What this server stores

- Your account: username, optional email, password hash, optional 2FA secret.
- Your library state, listening progress, bookmarks, ratings and reviews.
- Device sessions (device name, platform, app version, last seen). IP addresses are stored only in the audit log.
- Crash reports only if you opt in, sent only to this server.

## What it does not do

- No third-party analytics, trackers or ads.

## Your rights

- Export all your data (Settings → Account → Export).
- Delete your account (Settings → Account → Delete).
